# Linked List

Linked List is a linear data structure where the nodes (or elements) are linked together.

## Characteristics Of Linked List

- Nodes consists of _data_ and _pointer_
- _Pointer_ points to the next data.
- Not stored at _contiguous_ memory locations

## Types Of Linked List

- Singly Linked List
- Doubly Linked List
- Circular Linked List
  - Circular Singly Linked List
  - Circular Doubly Linked List
